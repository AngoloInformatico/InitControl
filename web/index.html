🟢 VERDE (Safe to Disable)

IMPATTO SISTEMA: NULLO
0 Elementi

Applicazioni utente note (Spotify, Discord, Steam, browser helper, updater commerciali). Possono essere disabilitati con totale serenità. Riducono il boot time e liberano fino a 2 GB di RAM all'accesso.

🟡 GIALLO (Caution)

IMPATTO: ACCESSORI / DRIVER
0 Elementi

Software per periferiche (Razer Synapse, Logitech G HUB, Corsair iCUE), pannelli audio Realtek, sincronizzatori cloud (OneDrive, Dropbox). La disabilitazione non danneggia Windows ma disattiva macro o sync automatica.

🔴 ROSSO (Critical)

PROTETTO CON DOPPIA CONFERMA
0 Elementi

Processi Windows Core, servizi di sicurezza (Windows Defender / Antivirus), driver hardware e storage controller. La disattivazione rischia di provocare schermate blu (BSOD) o mancato avvio. InitControl ne blocca la modifica accidentale.

Funzionalità Chiave dell'Applicazione
  • Oltre il Task Manager: Scansione aggregata di HKCU, HKLM, WoW6432Node Run/RunOnce, Startup Folders, Servizi terze parti e Attività Pianificate.
  • Rating a Semaforo: Separazione in Safe (Verde), Caution (Giallo), Critical (Rosso con Kernel Guard).
  • De-Offuscamento PE: Estrazione metadati, Editore, Firma Authenticode, SHA256 e intelligence euristica integrata.
  • Doppia Conferma Kernel Guard: Blocco protettivo contro la disabilitazione accidentale di componenti core di sistema.
  • Ripristino Snapshot: Cronologia completa dei punti di ripristino per annullare qualsiasi modifica in 1 click.
  • Sincronizzazione Versione: Tracciamento rigoroso tramite versione.json e metadati PE embedded nell'eseguibile.
